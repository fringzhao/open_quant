# 步骤四：因子有效性评估详解

本文整理自 `视频讲义/quant_intro_guide.pdf` 第 7 页和第 15 页，并结合当前项目的 `src/quant_infra/factor_analyze.py` 说明因子有效性评估的理论、计算方法与工程实现。

## 1. 为什么构造完因子还要评估

因子值本身只是一个数字。一个因子有明确的经济逻辑，并不代表它一定能够预测未来收益。

步骤四需要回答以下问题：

1. 因子值与未来收益是否存在稳定的相关关系？
2. 因子值越高，股票未来收益是否也呈现规律性变化？
3. 做多高因子股票、做空低因子股票能否获得正收益？
4. 收益是长期稳定产生的，还是由少数月份或极端股票贡献的？
5. 结果是否存在未来数据泄漏、幸存者偏差或换仓日期偶然性？

讲义主要通过两种方法回答这些问题：

- IC/IR 分析；
- 十组分层回测和多空组合分析。

## 2. 评估前的数据对齐

### 2.1 因子必须预测未来收益

假设在月份 `m` 的月底获得股票因子值 `Factor(i,m)`，评估时必须使用月份 `m+1` 的股票收益：

```text
Factor(i,m) → Return(i,m+1)
```

不能直接比较当月因子与当月收益，否则可能把因子形成期间已经发生的收益当成预测结果，形成未来数据泄漏。

讲义中的 IC 公式为：

```text
IC(m) = SpearmanCorr(Factor(i,m), Return(i,m+1))
```

其中 `i` 表示同一月份横截面上的不同股票。

### 2.2 横截面与时间序列的区别

IC 不是计算某一只股票在多年中的因子与收益相关性，而是在每个调仓日，对所有股票做一次横截面相关分析。

例如某个月底有四只股票：

| 股票 | 当月因子值 | 下月收益 |
| --- | ---: | ---: |
| A | 0.8 | 6% |
| B | 0.4 | 3% |
| C | -0.1 | 1% |
| D | -0.5 | -2% |

因子排序和下月收益排序完全一致，因此该月 IC 接近 1。

下一个月会重新使用当月所有股票计算一个新的 IC。最终得到一条 IC 时间序列：

```text
2026-01：0.08
2026-02：0.03
2026-03：-0.02
2026-04：0.06
...
```

## 3. IC：因子的横截面预测能力

### 3.1 IC 的定义

IC 是因子值与下一期收益之间的相关系数：

```text
IC = Corr(Factor, NextReturn)
```

讲义采用 Spearman 秩相关，而不是直接使用 Pearson 相关。

### 3.2 为什么使用 Spearman 相关

Spearman 只比较排序，不要求因子值与收益之间是线性关系。

例如：

```text
因子排名：A > B > C > D
收益排名：A > B > C > D
```

即使 A、B、C、D 的实际因子数值差距非常不均匀，只要排序一致，Spearman IC 仍然较高。

这对量化选股很合适，因为很多策略实际使用的是因子排名，而不是因子的绝对数值。

### 3.3 IC 的方向

- `IC > 0`：因子值越高，未来收益通常越高；
- `IC < 0`：因子值越高，未来收益通常越低；
- `IC ≈ 0`：因子排序与未来收益排序没有稳定关系。

负 IC 不一定代表因子无效。如果负 IC 长期稳定，可以反向使用该因子：做多低因子股票，做空高因子股票。

### 3.4 IC 均值

对每个调仓期计算 IC 后，再求时间序列均值：

```text
IC均值 = mean(IC(1), IC(2), ..., IC(T))
```

IC 均值表示因子长期的平均预测方向和预测强度。

讲义给出的经验标准是：

```text
|IC均值| > 0.03：具有一定参考价值
```

该数值只是经验阈值，不能脱离市场、样本、频率、交易成本和统计显著性单独判断。

## 4. IR：因子预测能力的稳定性

### 4.1 IR 的定义

讲义中的信息比率为：

```text
IR = IC均值 / IC标准差
```

其中：

- 分子衡量平均预测能力；
- 分母衡量 IC 在不同时间的波动；
- IR 衡量单位 IC 波动对应的平均 IC。

### 4.2 IR 的直观理解

假设两个因子的平均 IC 都是 `0.04`：

```text
因子 A：IC 标准差 = 0.04，IR = 1.00
因子 B：IC 标准差 = 0.12，IR = 0.33
```

虽然平均预测能力相同，但因子 A 的表现更稳定，因子 B 可能由少数月份的高 IC 拉动。

讲义给出的经验标准是：

```text
IR > 0.5：可以认为信号具有一定稳定性
```

如果因子的预期方向为负，应结合 IC 方向解释 IR，或者先统一因子方向后再比较。

## 5. 分层回测

IC 只说明排序相关性，不能直接告诉我们因子能产生多少收益。因此还需要进行分层回测。

### 5.1 月底截面排序

每个月底取得所有股票的因子值，由低到高排序并平均划分为 10 组：

```text
Group 1：因子值最低的 10%
Group 2：因子值较低的下一组 10%
...
Group 10：因子值最高的 10%
```

每组内部通常采用等权配置，即每只股票拥有相同权重。

### 5.2 使用下一期收益

在月份 `m` 的月底根据因子分组，然后在月份 `m+1` 持有对应股票：

```text
m 月月底形成分组
        ↓
m+1 月持有一个月并计算收益
        ↓
m+1 月月底重新计算因子和分组
```

这保证因子信息在投资决策时已经可用。

### 5.3 检查分层单调性

如果因子方向为正，理想结果应当是：

```text
Group 1 < Group 2 < ... < Group 9 < Group 10
```

现实中不要求每一组都严格递增，但整体应呈现比较清晰的趋势。

例如：

| 分组 | 年化收益 |
| --- | ---: |
| Group 1 | -4% |
| Group 2 | -1% |
| Group 3 | 2% |
| Group 4 | 3% |
| Group 5 | 5% |
| Group 6 | 7% |
| Group 7 | 8% |
| Group 8 | 11% |
| Group 9 | 13% |
| Group 10 | 16% |

这种结果说明因子不只能够区分最强和最弱股票，在中间区间也具有较好的排序能力。

如果只有 Group 10 收益很高、Group 1～9 没有规律，因子可能只对极端股票有效，也可能受到异常值影响。

## 6. 多空组合

### 6.1 多空收益

对于正向因子，讲义构造：

```text
多头 = Group 10
空头 = Group 1

LongShortReturn(m)
= Group10Return(m) - Group1Return(m)
```

多空组合尽量抵消市场整体涨跌，突出因子排序本身带来的收益差异。

例如：

```text
Group 10 当月收益：5%
Group 1 当月收益：1%
多空收益：5% - 1% = 4%
```

即使市场整体上涨，只要高因子组比低因子组表现好，多空组合仍然可以获得正收益。

对于稳定负 IC 的因子，多空方向应反转：

```text
低因子组收益 - 高因子组收益
```

### 6.2 多空组合的累计收益

若每期多空收益为 `r(t)`，累计净值应按复利计算：

```text
净值(T) = ∏(1 + r(t))
```

不能简单把长期收益率相加，因为实际投资过程中收益会在上一期净值基础上继续累积。

## 7. 夏普比率

夏普比率衡量单位波动所获得的平均收益。

讲义按月度多空收益计算：

```text
月度夏普 = mean(LongShortReturn) / std(LongShortReturn)

年化夏普
= 月度夏普 × sqrt(12)
```

夏普比率越高，代表多空收益相对于自身波动越有吸引力。

需要注意，严格的夏普比率通常应扣除无风险利率。讲义中的公式近似假设短期无风险收益为 0，或者将其忽略。

## 8. IC 与分层回测为什么要同时使用

两个方法回答的问题不同：

| 方法 | 主要回答的问题 |
| --- | --- |
| IC | 因子排序与未来收益排序是否相关？ |
| IR | 这种相关关系是否稳定？ |
| 分层收益 | 因子是否具有整体单调性？ |
| 多空收益 | 最强组相对最弱组能赚多少？ |
| 夏普比率 | 多空收益是否具有较好的风险收益比？ |

可能出现以下情况：

### 情况一：IC 高，但多空收益低

因子能够正确排序，但各组之间实际收益差异很小，扣除交易成本后可能无法交易。

### 情况二：IC 低，但多空收益高

可能只有最极端的两组有效，中间股票排序混乱；也可能收益由少数异常月份贡献。

### 情况三：平均 IC 高，但 IR 低

因子偶尔非常有效，但多数时期方向不稳定。

### 情况四：分层单调，但多空夏普低

因子方向正确，但收益波动太大，持有体验和实盘风险较差。

因此，不能只看某一个评价指标。

## 9. 当前项目的实际计算流程

当前项目的主要入口是：

```python
evaluate_factor(
    factor_table,
    fac_freq,
    bench_index,
    other_name=None,
    samples=None,
    n_groups=10,
)
```

实际执行流程如下。

### 9.1 加载数据

`prepare_evaluate_data()` 读取：

- 指定因子表；
- `stock_bar` 中的股票日收益；
- 基准指数收益；
- 指数成分股文件或通过 `get_ins()` 获取的成分股。

股票涨跌幅 `pct_chg` 会除以 100 转为小数收益率，并进行缩尾处理，降低极端收益对结果的影响。

### 9.2 生成不同评估组合

项目可以同时评估：

- 不同样本，例如中证 800、中证 1000、全市场；
- 不同调仓频率，例如日度、周度、月度。

因子本身为某一频率时，只评估不低于该因子频率的调仓方案。

### 9.3 聚合周期数据

对于周频或月频：

- 股票收益使用复利累计：`(1 + return).prod() - 1`；
- 因子值使用周期内最后一个有效值；
- 使用 `shift(-1)` 获得下一期股票收益。

对于日频：

- 直接使用日频收益和因子；
- 下一期收益是下一个实际交易日收益。

### 9.4 计算 Rank IC

当前代码先将数据转换为宽表：

```text
行：trade_date
列：ts_code
值：factor 或 next_return
```

然后在每个日期内部把因子和收益转换成百分比排名，再计算排名之间的 Pearson 相关系数。

排名后的 Pearson 相关系数等价于 Spearman 相关系数。

项目只保留股票数量大于 `MIN_IC_SIZE` 的日期，避免样本过少时计算出不可靠的 IC。

### 9.5 十组划分

当前代码使用因子横截面百分比排名划分组别：

```text
group = ceil(factor_rank × n_groups)
```

并通过 `clip(1, n_groups)` 保证分组编号处于 1～10。

`method='first'` 用于处理相同因子值，使相同值按照原始顺序获得不同排名，避免分位点重复导致 `qcut` 失败。

### 9.6 下一期持仓

当前期的分组标签会映射到下一持有周期：

```text
hold_period = factor_period + 1
```

再与下一周期的股票日收益合并。这样即使采用月频调仓，组合收益曲线仍然可以保留为日频。

### 9.7 计算日度组合收益

每天对同组股票收益取算术平均，得到等权组合日收益：

```text
GroupDailyReturn(t)
= mean(组内所有股票在 t 日的收益)
```

然后计算：

```text
Long(t) = Group10DailyReturn(t)
Short(t) = Group1DailyReturn(t)
LongShort(t) = Long(t) - Short(t)
```

### 9.8 计算分组年化收益

当前代码使用日收益复利并按 242 个交易日年化：

```text
GroupAnnualReturn
= [∏(1 + DailyReturn)]^(242 / 交易日数) - 1
```

### 9.9 计算日频年化夏普

当前代码的多空收益是日频序列，因此使用：

```text
AnnualSharpe
= mean(DailyLongShortReturn)
  / std(DailyLongShortReturn)
  × sqrt(242)
```

这与讲义第 7 页基于月度收益乘 `sqrt(12)` 的公式不同。两种年化方式分别适用于日频和月频收益序列，不能混用。

### 9.10 索提诺比率

当前项目还计算讲义没有重点展开的索提诺比率。

索提诺比率只使用负收益计算下行风险：

```text
DownsideDeviation
= sqrt(mean(min(Return, 0)^2))

AnnualSortino
= mean(Return) / DownsideDeviation × sqrt(242)
```

项目分别计算最高因子组和最低因子组的索提诺比率。

`evaluate_factor()` 会产生三类输出。

factor_mining/{factor_table}/output/summary.csv

包含每个日期的 IC，以及对应的样本和频率。

## 11. 一个完整示例

假设在 2026 年 1 月底，根据某个因子将 1,000 只股票分为 10 组。

### 11.1 IC 计算

比较 1 月底因子排名和 2 月股票累计收益排名：

```text
2026-01 IC = 0.06
```

对全部月份重复计算后得到：

```text
IC均值 = 0.04
IC标准差 = 0.06
IR = 0.04 / 0.06 = 0.67
```

按照讲义经验标准，该因子具有一定预测能力和稳定性。

### 11.2 分层回测

假设长期统计结果为：

```text
Group 1 年化收益： 2%
Group 5 年化收益： 8%
Group 10 年化收益：17%
```

各组整体随因子值增加而上升，说明因子具有较好的单调性。

### 11.3 多空组合

```text
多空年化收益约为：17% - 2% = 15%
```

实际多空年化收益应通过逐日或逐月多空收益复利计算，不能简单使用两个年化收益相减；这里仅用于直观说明。

如果多空组合年化夏普为 1.2，说明收益相对于波动具有一定吸引力。但在决定是否实盘使用前，仍需加入交易费用和可交易性约束。

## 12. 常见错误与风险

### 12.1 使用同期收益

错误做法：

```text
Factor(m) 与 Return(m) 比较
```

正确做法：

```text
Factor(m) 与 Return(m+1) 比较
```

### 12.2 忽略因子发布时间

如果因子依赖财务报告，不能使用报告期末日期作为可用日期，应使用公告日期或数据实际可获得日期。

### 12.3 使用当前成分股回测历史

使用今天的指数成分股回测多年历史，会产生幸存者偏差。严谨回测应使用每个历史时点实际生效的成分股。

### 12.4 忽略停牌和涨跌停

理论分组不代表股票一定能够按收盘价买入。实盘回测需要处理：

- 停牌；
- 涨停无法买入；
- 跌停无法卖出；
- 新股上市时间不足；
- 退市股票；
- ST 股票过滤。

### 12.5 忽略交易成本

分组回测通常会产生换手，应进一步扣除：

- 佣金；
- 印花税；
- 滑点；
- 市场冲击成本。

高换手因子可能在未扣费时表现很好，扣费后失去实际价值。

### 12.6 只看总样本结果

应进一步检查：

- 牛市和熊市；
- 大盘股和小盘股；
- 不同行业；
- 不同年份；
- 不同调仓日；
- 不同持有周期。

如果因子只在某个短时期有效，可能是偶然现象或参数过拟合。

### 12.7 忽略统计显著性

除了 IC 均值和 IR，还可以计算：

- IC 均值的 t 统计量；
- IC 为正的月份比例；
- Newey-West 调整后的显著性；
- Bootstrap 置信区间；
- 多空收益最大回撤。

## 13. 如何判断一个因子值得继续研究

建议至少同时检查以下维度：

| 维度 | 关注点 |
| --- | --- |
| 经济逻辑 | 因子是否有合理机制，而不只是数据拟合 |
| IC 均值 | 是否长期偏离 0，方向是否符合预期 |
| IR | IC 是否稳定 |
| IC 胜率 | IC 方向正确的时期占比 |
| 分层单调性 | 组收益是否随因子值规律变化 |
| 多空收益 | 高低组是否存在足够收益差 |
| 夏普比率 | 多空收益是否覆盖自身波动 |
| 最大回撤 | 最坏时期是否能够承受 |
| 换手率 | 扣除交易成本后是否仍然有效 |
| 子样本稳健性 | 不同年份、市场状态和股票池是否有效 |

一个比较可靠的因子通常不是某项指标极高，而是在多个维度上都表现合理，并且经过交易成本和样本外检验后仍然有效。

## 14. 步骤四的核心总结

步骤四可以归纳为以下流程：

```text
当期因子值
    ↓
与下一期收益严格对齐
    ↓
每期计算横截面 Rank IC
    ↓
计算 IC 均值与 IR
    ↓
按因子排名划分 10 组
    ↓
下一期持有并统计分组收益
    ↓
检查收益单调性
    ↓
构造最高组减最低组的多空组合
    ↓
计算累计收益、夏普比率和下行风险
    ↓
结合交易成本与稳健性判断是否可用
```

IC/IR 说明因子是否具有统计上的预测关系；分层回测和多空组合说明这种关系是否能够转化为投资收益。只有两类证据都比较稳定，因子才值得进入下一步的投资组合构建和回测。
