# 步骤三：因子构建的核心步骤

本文整理自 `视频讲义/quant_intro_guide.pdf` 第 6、13、14 页，并结合当前项目代码说明其计算过程。

## 1. 因子构建的目标

该步骤的目标是利用 Carhart 四因子模型，先剥离股票收益中由市场、规模、价值和动量造成的公共影响，再比较周一与其他工作日的特质收益差异，构造个股月频因子。

## 2. 准备四个基础定价因子

首先需要计算每日四因子：

| 因子 | 含义 |
| --- | --- |
| MKT | 市场整体收益 |
| SMB | 小市值组合收益减去大市值组合收益 |
| HML | 价值组合收益减去成长组合收益 |
| UMD | 强势组合收益减去弱势组合收益 |

这些因子用于解释股票收益中由市场公共风险造成的部分。

## 3. 将每只股票的数据分成两组

对每只股票的日收益进行拆分：

- 周一组：`weekday == 0`；
- 周内组：周二至周五，即 `weekday != 0`。

讲义中的“周末组”实际使用周一收益作为代理。由于周末市场不交易，周末积累的信息通常集中反映在周一价格中。

## 4. 分别执行 OLS 回归

对周一和周内数据分别估计一套 Carhart 四因子模型：

```text
股票收益
= α
+ βMKT × MKT
+ βSMB × SMB
+ βHML × HML
+ βUMD × UMD
+ ε
```

因此，每只股票会得到两套系数：

```text
周一组：αMonday、βMonday
周内组：αWeekday、βWeekday
```

分别回归是因为股票在周一和普通工作日对市场因子的敏感程度可能不同。

## 5. 计算每日残差

先利用估计出的系数计算模型预测收益：

```text
预测收益
= α
+ βMKT × MKT
+ βSMB × SMB
+ βHML × HML
+ βUMD × UMD
```

然后计算残差：

```text
残差 = 股票实际收益 - 模型预测收益
```

残差 `ε` 表示无法被市场、规模、价值和动量解释的股票特质收益。

例如：

```text
实际收益：1.20%
模型预测：0.80%
残差收益：0.40%
```

这意味着其中约 0.4 个百分点无法由四个公共风险因子解释。

## 6. 按月聚合残差

分别计算每只股票每个月的：

```text
月度周一残差均值
= 当月所有周一残差的平均值

月度周内残差均值
= 当月所有周二至周五残差的平均值
```

月度聚合可以减少单日噪声，形成适合月度选股的因子。

## 7. 构造最终因子

讲义给出的最终因子为：

```text
F(i,m)
= 股票 i 在月份 m 的周一残差均值
- 股票 i 在月份 m 的周内残差均值
```

例如：

```text
当月周一残差均值： 0.30%
当月周内残差均值：-0.05%

因子值 = 0.30% - (-0.05%) = 0.35%
```

`F > 0` 表示该股票不能被四因子解释的收益更多地集中在周一，可能反映周末积累的信息在周一集中进入价格。

## 8. 完整数据流程

```text
股票日收益 + MKT/SMB/HML/UMD
              ↓
       区分周一和周内
              ↓
       分别执行 OLS 回归
              ↓
        计算每日残差
              ↓
       按股票、月份聚合
              ↓
周一残差均值 - 周内残差均值
              ↓
          月频选股因子
```

## 9. 工程实现优化

讲义第 13～14 页提出了以下工程优化：

1. 一次性读取股票行情和定价因子，在内存中按股票分组，避免多个并行线程频繁访问 DuckDB；
2. 将股票的两套 Beta 保存到 `stock_betas`，后续计算直接复用；
3. 只对尚未缓存 Beta 的股票执行回归；
4. 使用 Joblib 按股票并行计算，提高全市场因子构建速度；
5. 股票至少需要 50 个交易日的数据才能参与回归。

## 10. 需要注意的计算口径

### 10.1 残差均值不等于特质波动率

讲义的最终公式计算的是“残差均值之差”，严格来说属于特质收益差，而不是特质波动率之差。

如果要衡量特质波动率，应使用残差标准差，例如：

```text
std(周一残差) - std(周内残差)
```

### 10.2 全历史回归可能产生未来数据泄漏

如果在历史回测中使用包含未来数据的全历史样本估计 Beta，会产生未来数据泄漏。更严谨的实现应使用：

- 滚动窗口回归；或
- 仅使用因子形成日期以前数据的扩展窗口回归。

## 11. 与当前项目代码的差异

讲义描述的算法与当前 `src/quant_infra/factor_calc.py` 并不完全一致。

当前代码的处理方式是：

1. 对每只股票的全部有效交易日只估计一套 Beta，而不是分别估计周一和周内 Beta；
2. 单只股票至少需要 220 个有效交易日，而讲义要求至少 50 个交易日；
3. 使用四因子模型计算每日残差；
4. 使用最近 20 个交易日残差的滚动标准差作为特质波动率因子；
5. 结果写入 `spec_vol` 表。

当前实现的核心公式为：

```text
resid = 实际收益 - 四因子模型预测收益

spec_vol(t) = std(resid(t-19), ..., resid(t))
```

因此，两者的区别是：

| 对比项 | PDF 讲义 | 当前项目代码 |
| --- | --- | --- |
| Beta 分组 | 周一、周内分别回归 | 全部交易日统一回归 |
| 最小样本 | 50 个交易日 | 220 个交易日 |
| 聚合频率 | 月频 | 日频滚动窗口 |
| 最终因子 | 周一残差均值减周内残差均值 | 20 日残差标准差 |
| 因子含义 | 周末信息效应或特质收益差 | 特质波动率 |
